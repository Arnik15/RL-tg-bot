# 🤖 Telegram-бот для управления Linux-сервером

Бот для удалённого администрирования Linux-сервера через SSH 
и выполнения прикладных задач: поиск email/телефонов в тексте, 
проверка сложности пароля, сбор системной информации.

## 📌 Возможности

### Прикладные задачи
- **Поиск email** в произвольном тексте (регулярные выражения).
- **Поиск номеров телефонов** с нормализацией к формату `+7XXXXXXXXXX`.
- **Проверка сложности пароля** по регулярному выражению 
  (заглавные/строчные, цифры, спецсимволы, минимум 8 символов).

### Мониторинг сервера через SSH
| Команда | Что показывает |
| :--- | :--- |
| `/get_release` | Информация о релизе ОС |
| `/get_uname` | Информация о системе (`uname -a`) |
| `/get_uptime` | Время работы системы |
| `/get_df` | Состояние дисков |
| `/get_free` | Состояние памяти |
| `/get_mpstat` | Загрузка CPU |
| `/get_w` | Активные пользователи |
| `/get_auths` | Последние 10 входов |
| `/get_critical` | Критические события из журнала |
| `/get_ps` | Топ-20 процессов по CPU |
| `/get_ss` | Используемые порты |
| `/get_services` | Запущенные сервисы |
| `/get_apt_list` | Установленные пакеты (с поиском по имени) |

## 🛠️ Стек

- **Python 3.10+**
- **python-telegram-bot** — Telegram Bot API
- **paramiko** — SSH-подключения
- **python-dotenv** — загрузка конфигурации из `.env`
- **re** — регулярные выражения для поиска и валидации
